# Security Policy

Client Forum integrates directly with your WHMCS client area's authentication system, so we take security reports seriously and appreciate responsible disclosure.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 2.2.x (latest free release) | ✅ |
| < 2.2.0 | ❌ |

Only the current release is actively maintained. If you're running an older version, please update before reporting an issue that may already be fixed.

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.** Public issues are visible to anyone, including before a fix is available.

Instead, email **Support@knkws.com** with:

- A description of the vulnerability and its potential impact
- Steps to reproduce it (proof-of-concept code or screenshots are helpful, if applicable)
- The version of Client Forum and WHMCS you tested against

## What to Expect

- We'll acknowledge your report within a few business days.
- We'll investigate and let you know whether it's confirmed, and give a rough timeline for a fix if so.
- Once a fix is released, we're happy to credit you in the changelog or release notes if you'd like — just let us know your preference when reporting.

## Scope

This policy covers the Client Forum addon module itself (SSO handling, post/thread permissions, admin access controls, rate limiting). It does not cover the security of your underlying WHMCS installation, server, or hosting environment — please report those directly to WHMCS or your hosting provider as appropriate.

Thank you for helping keep Client Forum and the businesses that run it secure.
